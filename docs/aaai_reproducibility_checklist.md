# AAAI Reproducibility Checklist — drafted answers

Answers reflect what this suite actually does; verify each against the
final camera-ready before submission.

**This paper:**

1. *Includes a conceptual outline/pseudocode of the algorithm(s)?* **Yes** —
   the naming-game engine, environment loops, and battery are specified in
   RESULTS.md §1/§7 and in module docstrings (`namegame/core`, `namegame/envs`).
2. *Clearly delineates statements that are opinions/hypotheses vs objective
   fact?* **Yes** — the honesty table (RESULTS.md §8) labels every result
   family pre-registered / exploratory / failed-instrument.
3. *Provides well-marked pedagogical references?* **Yes** — Lewis
   conventions, naming game, Axtell–Epstein–Young classes cited in §7.

**Theory:** no theoretical claims requiring proof; N/A.

**Datasets:** no external datasets. All corpora are generated by the suite
itself; every raw journal ships in the supplementary (or regenerates
deterministically from the seed manifest).

**Code and experiments:**

1. *Code, with specification of dependencies?* **Yes** — the full source is
   the supplementary snapshot (`dist/repro_snapshot.zip`); dependencies:
   numpy, scipy, pandas, matplotlib, anthropic, requests, pytest (README).
2. *Training code / evaluation code?* N/A (no training) / **Yes** —
   `python -m namegame {expa,expb,envs,analyze}` reproduce every number.
3. *Pre-trained models?* Third-party APIs (claude-haiku-4.5,
   claude-sonnet-4.5, gpt-5-mini via OpenRouter); exact model ids and
   routing recorded per run in each `summary.json`.
4. *README with instructions?* **Yes**, including the free full-pipeline
   mock mode which requires no API access.
5. *Specification of all hyperparameters and how they were chosen?*
   **Yes** — every run's resolved config is journaled; protocol-
   underdetermined choices are in the decision log (RESULTS.md §2) with
   rationale, fixed before the affected data collection.
6. *Number of runs, and statistics reported?* **Yes** — per-cell ns in the
   claims→evidence table; exact (Clopper–Pearson) or bootstrap CIs
   throughout; no result is a single run.
7. *Randomness controlled / seeds reported?* **Yes** — full determinism in
   the substrate tier; LLM tiers journal every interaction before the next
   begins and are exactly resumable; `dist/seed_manifest.json` lists every
   seed. LLM sampling is the one uncontrolled source (temperature as per
   provider default), which population-level replication (n per cell)
   addresses.
8. *Compute infrastructure reported?* **Yes** — commodity CPU container;
   live tiers are API-bound; spend and call counts recorded in
   `cost_state.json` per results directory and reported in RESULTS.md.
9. *Analysis scripts?* **Yes** — `namegame/analysis/*` and `scripts/*`
   regenerate all figures, `numbers.tex`, and RESULTS.md from raw journals.
